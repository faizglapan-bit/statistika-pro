# Statistika Pro — Backend API

Backend API layanan analisis statistik profesional berbasis FastAPI.
Menyediakan kalkulasi analisis deskriptif, korelasi, regresi, uji instrumen (validitas & reliabilitas Cronbach Alpha), ekspor APA 7 (PDF, DOCX, XLSX), dan manajemen dataset.
